# 要件定義書 — 英単語穴埋めクイズWebアプリ

- 版数:v1.3(確定版)
- 作成日:2026-07-05
- ステータス:承認済み

---

## 1. アプリ概要

TOEIC単語を対象とした、英語例文の穴埋め形式で学習するクイズWebアプリ。
学習コンテンツ(例文・定義・類義語)はすべて英語で提供し、英語を英語のまま理解するトレーニングを兼ねる。

本アプリの特徴は以下の2点。

1. **類似度パーセント表示** — 入力単語と正解単語の「近さ」を%で表示し、惜しいミス(スペルミス、r/L混同など)からも学べる
2. **習熟度システム** — ヒントの使用状況を単語ごとの習熟度に反映し、本当に覚えている単語とそうでない単語を可視化する

## 2. 対象・前提

| 項目 | 内容 |
|------|------|
| プラットフォーム | Webアプリ(PC・スマホのブラウザ両対応、レスポンシブ) |
| 単語データ | TOEIC頻出単語 |
| レベル | 選択制(TOEICスコア帯:400 / 600 / 800 / 900+ を想定) |
| 学習コンテンツの言語 | すべて英語(日本語訳は表示しない) |
| UIの言語 | 日本語 |
| 公開 | Web上への公開を想定 |
| ユーザー管理 | ログイン機能あり(学習履歴をアカウントに紐づけて保存) |

## 3. 機能要件

### 3.1 出題・解答(メイン機能)

- 英語例文の穴埋め形式で出題する(対象単語を「_____」で伏せ字にする)
- ユーザーは空欄に入る英単語をタイプ入力して解答する
- 例:`He felt _____ sitting in the new office chair.` → 答え `comfortable`

### 3.2 類似度判定(コア機能)

入力単語と正解単語の類似度をパーセントで表示する。算出要素は以下のとおり。

- 文字数の一致度
- 各文字の正しさ(位置・文字の一致)
- **r ↔ L の混同**は通常のミスより減点を軽くする(日本人学習者への配慮)
- **隣接文字のズレ**(アルファベットの前後繋がりのミス)は減点を軽くする

### 3.3 ヒント機能(全5種)

以下の5種類のヒントを、**自由な順番・タイミング**で開くことができる。

| # | ヒント | 内容 |
|---|--------|------|
| 1 | 定義 | 単語の定義を英語で表示 |
| 2 | 類義語 | 類義語を英語で表示 |
| 3 | 発音 | 単語の発音を音声再生 |
| 4 | シャッフル文字 | 正解のアルファベットを並べ替えて提示 |
| 5 | イメージイラスト | 状況説明イラストで単語のイメージを視覚的に補完 |

### 3.4 習熟度システム

- 単語ごとに習熟度を記録する
- 正解すると習熟度が上がる
- **ヒントを使用すると習熟度の上がり幅が減る**(ヒントの種類・使用数に応じて)
- 習熟度はユーザーアカウントに紐づけてサーバー側(DB)に保存する

### 3.5 ユーザー管理

- 新規登録・ログイン機能(メールアドレス+パスワード)
- 学習履歴・習熟度はアカウント単位で管理し、端末をまたいで引き継げる

## 4. 非機能要件

- 類似度判定は解答確定時に即時表示する
- スマホの画面サイズでも操作しやすいレスポンシブ対応
- パスワードは平文保存しない(ハッシュ化)
- Web公開時はHTTPSを前提とする

## 5. スコープ外(初期版では実装しない)

- ソーシャルログイン(Google等)
- ランキング等のユーザー間機能
- 日本語訳の表示
